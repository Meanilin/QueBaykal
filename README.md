# Cinema Queue Bot

Telegram-бот для совместного выбора фильма. Участники предлагают варианты, голосуют 👍, бот собирает очередь по числу голосов.

## Стек

- Python 3.10+
- [aiogram 3.x](https://docs.aiogram.dev/) — Telegram Bot API
- in-memory store (для постоянного хранения — Redis/Postgres)

## Быстрый старт

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# впишите BOT_TOKEN от @BotFather и (опц.) ADMIN_IDS — свой Telegram user id
```

Получить свой id: напишите в любой бот `/start` или используйте [@userinfobot](https://t.me/userinfobot).

```bash
python bot.py
```

## Команды

| Команда | Описание |
|---|---|
| `/start`, `/help` | Справка |
| `/movies` | Список фильмов с инлайн-кнопками (голосование, удаление, пагинация) |
| `/add` | Предложить фильм (FSM-диалог) |
| `/queue` | Итоговая очередь по числу голосов |
| `/cancel` | Отменить текущий ввод |

## Как работает

- Кнопка 👍 — toggle: повторное нажатие снимает голос.
- Удалять может автор фильма или `ADMIN_IDS`.
- Пагинация по 5 фильмов на страницу.
- Сортировка: сначала больше голосов, при равенстве — раньше добавлен.

## Тесты

```bash
python test_logic.py
```

Проверяет: создание, голосование, повторное нажатие (снятие), удаление (владелец/чужой), порядок очереди.

## Что подключить для продакшна

1. **Персистентное хранилище** — заменить `MovieStore` на Redis (например, `aiogram.fsm.storage.redis`) или SQL через SQLAlchemy/asyncpg.
2. **Защита токена** — `.env` в `.gitignore`, секреты только из переменных окружения.
3. **Деплой** — systemd unit, Docker, или `pm2`.
4. **Rate limit** на `/add`, чтобы не спамили.
5. **Уведомление в группу** — завести бота в чат, сделать `/movies @username` для упоминаний.
